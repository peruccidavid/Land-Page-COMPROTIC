## 📖 Descripción del Proyecto

**COMPROTIC** es una plataforma web institucional moderna, de alta fidelidad estética (*Cyber-Enterprise Dark Theme*) y 100% responsiva, diseñada para exhibir las capacidades tecnológicas del Complejo Productivo de Tecnología de Información y Comunicación.

La organización fue creada formalmente mediante el **Punto de Cuenta No. 025/2016** bajo el Vicerrectorado de Investigación, Desarrollo e Innovación (VIDI) de la **Universidad Nacional Experimental Politécnica de la Fuerza Armada Nacional (UNEFA)**, con la misión de integrar la investigación, desarrollo e innovación (I+D+i) al esfuerzo productivo de Venezuela.

---

## 🎯 Propósito y Objetivo General

COMPROTIC integra la **investigación, desarrollo e innovación (I+D+i)** al esfuerzo productivo de Venezuela mediante servicios especializados de **software**, **hardware** y **formación continua** que fortalecen las capacidades tecnológicas del país:

- ✅ Desarrollo de soluciones tecnológicas propias y soberanas.
- ✅ Servicios especializados para industrias, entes del Estado y comunidades.
- ✅ Formación continua en tecnología, software y electrónica.
- ✅ Innovación continua y generación de soluciones de vanguardia.
- ✅ Vinculación directa de la academia con el aparato productivo nacional.

## 🏭 Cuatro Unidades Estratégicas

### A. Centro de Desarrollo de Tecnología
- Innovación en software bajo estándares **COVENIN e ISO**.
- Diseño de hardware y sistemas embebidos.
- Fomento absoluto del **software libre** para la soberanía del conocimiento.

### B. Laboratorio de Manufactura (UNEFABLAB)
- Manufactura digital y aditiva: **impresión 3D, CAD/CAM**.
- Diseño digital avanzado y simulación de esfuerzo.
- Consultoría de proyectos I+D+i.

### C. Centro de Cómputo
- Cómputo de alto rendimiento **(HPC)** para sectores clave.
- Soporte al sector científico, empresarial y de seguridad de la nación.
- Análisis de datos intensivo.

### D. Unidad de Control y Calidad de Producción
- Aseguramiento de la calidad de productos tecnológicos.
- Auditoría final de software/hardware.
- Entrega formal a clientes, al **VIDI** y a **C-EPSU** (Incubadoras/Clústeres de EPSU Universitarias).

## 🚗 Proyecto Vehículo Explorador CUNAGUARO

La plataforma incluye una sección destacada para el **Vehículo Terrestre no Tripulado (UGV) CUNAGUARO 6x6**, un proyecto de robótica táctica desarrollado por **COMPROTIC-UNEFA** para misiones de reconocimiento, monitoreo y seguridad en terrenos hostiles.

### Características del proyecto
- Sistema de transmisión **6x6** con alta capacidad de tracción.
- Suspensión tipo **rocker-bogie** para terrenos irregulares.
- Suite de cámaras para exploración y monitoreo.
- Brazo manipulador opcional para misiones de rescate.
- Enlace directo en la página principal y el menú de navegación hacia la página del proyecto.

## 💻 Instalación y Visualización Local

La aplicación está diseñada con estándares web nativos sin requerir compiladores ni dependencias de Node.js locales. Se puede ejecutar inmediatamente en cualquier entorno:

### Opción 1: Apertura Directa en el Navegador (Método más rápido)
1. Clona o descarga este repositorio en tu computadora.
2. Haz doble clic en el archivo `index.html`.
3. Se abrirá inmediatamente en tu navegador preferido (*Google Chrome, Microsoft Edge, Brave, Firefox, Safari*).

---

### Opción 2: Servidor Local con Python 3
Si tienes Python instalado, puedes levantar un servidor HTTP local en segundos:

```bash
# 1. Abre la terminal en el directorio del proyecto
cd NUEVA_WEB_COMPROTIC

# 2. Inicia el servidor HTTP en el puerto 8000
python -m http.server 8000

# 3. Abre tu navegador en:
# http://localhost:8000
```

---

### Opción 3: Servidor Local con Node.js / npx
Si utilizas el ecosistema de Node.js:

```bash
# Ejecuta un servidor estático instantáneo sin instalar nada global
npx serve .

# O con http-server
npx http-server -p 8080
```

---

### Opción 4: Extensión Live Server en VS Code
1. Abre la carpeta del proyecto en **Visual Studio Code**.
2. Instala la extensión **Live Server** (por *Ritwick Dey*).
3. Haz clic derecho sobre `index.html` y selecciona **"Open with Live Server"**.

## 🚀 Guía para Subir el Proyecto a GitHub

Sigue estos sencillos pasos desde la terminal de tu computadora para crear el repositorio y publicar tu proyecto en GitHub:

### Paso 1: Inicializar el repositorio Git local
```bash
# Ubícate en la raíz del proyecto
cd c:\Users\Paola\Desktop\NUEVA_WEB_COMPROTIC

# Inicializa Git (si no está inicializado)
git init

# Agrega todos los archivos del proyecto
git add .

# Realiza el commit inicial
git commit -m "feat: lanzamiento inicial de COMPROTIC - Plataforma Institucional UNEFA VIDI"
```

### Paso 2: Crear el nuevo repositorio en GitHub
1. Ingresa a tu cuenta de [GitHub](https://github.com/new).
2. Haz clic en **"New repository"**.
3. Nombra tu repositorio (por ejemplo: `comprotic-web` o `nueva-web-comprotic`).
4. Selecciona si deseas que sea **Público** o **Privado**.
5. **No marques** las casillas de inicializar con README o .gitignore (ya los tenemos creados localmente).
6. Haz clic en **"Create repository"**.

### Paso 3: Vincular el repositorio remoto y subir el código
Copia y ejecuta los siguientes comandos en tu terminal (reemplazando `TU_USUARIO` y `TU_REPOSITORIO` con tus datos de GitHub):

```bash
# Asignar la rama principal como 'main'
git branch -M main

# Vincular el repositorio remoto de GitHub
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git

# Enviar los cambios a GitHub
git push -u origin main
```

---

### Paso 4: Publicar gratis en GitHub Pages (Opcional pero Recomendado)
Para que cualquier persona pueda visitar la página web en vivo desde internet de forma gratuita:

1. En tu repositorio de GitHub, ve a la pestaña **Settings** (Configuración).
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En la sección **Build and deployment**:
   - **Source**: Selecciona `Deploy from a branch`.
   - **Branch**: Selecciona `main` y la carpeta `/(root)`.
4. Haz clic en **Save**.
5. En un par de minutos, GitHub te proporcionará una URL pública activa (ej. `https://TU_USUARIO.github.io/TU_REPOSITORIO/`).
